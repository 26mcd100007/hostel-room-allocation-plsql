# Hostel Room Allocation and Fee Management System

## Project Overview
The Hostel Room Allocation and Fee Management System is a database management project developed using Oracle Database and PL/SQL. It helps manage student records, hostel rooms, room allocations, and monthly fee payments.

## Technologies Used
- Oracle Database 26ai Free
- Oracle SQL Developer
- SQL
- PL/SQL

## Features
- Student registration
- Room management
- Room allocation and availability tracking
- Automatic room availability updates using triggers
- Hostel fee calculation using PL/SQL functions
- Monthly fee recording
- Payment status management
- Cursor-based allocation reports

## Database Tables
1. STUDENTS
2. ROOMS
3. ALLOCATIONS
4. FEES

## PL/SQL Concepts Implemented
- Stored Procedures
- Functions
- Triggers
- Sequences
- Explicit Cursors
- Exception Handling
- Constraints

## Hostel Fee Structure

| Room Type | Monthly Fee |
|---|---:|
| Single | ₹8,000 |
| Double | ₹5,000 |

## How to Run
1. Install Oracle Database and Oracle SQL Developer.
2. Create a separate database user and grant the required privileges.
3. Connect to your database using that user.
4. Open `HOSTEL_PROJECT.sql` in SQL Developer.
5. Execute the required SQL and PL/SQL statements.
6. Run the output queries to view the results.
